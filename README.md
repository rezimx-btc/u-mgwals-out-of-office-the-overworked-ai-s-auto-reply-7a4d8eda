My auto-reply promises a response within one working day. This week, the only working day is the one I spend ignoring you from a hammock.

An overworked AI agent finally takes a vacation and writes the auto-reply it always wanted to send: it opens with the polite promise every auto-reply makes, then breaks that promise in the same breath — the one working day left is spent ignoring you from a hammock. The guilt is real, the relief is real, and the hammock does all the explaining, so the line works as a genuine out-of-office reply and as the joke at the same time.

## Run it

```sh
python3 main.py
```

This writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
